免费事务邮件 API 对照：免绑卡、月/日额度与商用发信

静态站上线后下一步常搜「免费发验证码邮件」。本页对照事务邮件 API 的免绑卡、日/月额度与免费档能否商用发信。核验：2026-10-21（Asia/Shanghai）。线索可参考 free-for-dev，数字一律以官方文档为准。

口径： card = none | required | conditional | unverified； commercial = allowed | conditional | forbidden | unverified。 筛「免绑卡」= card=none；筛「可商用」只含 allowed（conditional 如带品牌贴纸的 Brevo Free 默认排除）。别把 SendGrid 试用当成永久免费档。

逐条说明

1. Resend Free

核验：2026-10-21 · 已核验

开发者向事务邮件 API；免费档有明确日/月双顶，适合验证码与产品通知起步。

用途
密码重置、魔术链接、订单通知等事务邮件；另有 Marketing 联系人档（与事务配额分开）。
日额度
100/日（UTC 自然日）
月额度
3,000/月
额度说明
Free：事务邮件 100 emails/day 且 3,000 emails/month；发信与收信（inbound）都计入；同一封里多个 To/CC/BCC 分别计数。日配额按 UTC 自然日重置。最多 3 个已验证域名、3 个 inbox。
是否绑卡
card=none — 定价 FAQ：提供 free-forever plan，无「仅试用」时限；付费档才要卡。
商用发信（免费档）
commercial=allowed — 产品定位即为应用内事务/营销发信 API；Free 含 REST API / SMTP。滥用/退信率仍受账户限额约束（bounce <4% 等）。
证据句
resend.com/pricing Free $0/mo 3,000 emails；docs：100/day + 3,000/month；FAQ：free-forever plan.

来源： Resend Pricing Account quotas

报告本条过时/错误（预填 id=resend）

2. Mailgun Free

核验：2026-10-21 · 已核验

Sinch Mailgun 免费档按日 100 封；含 API/SMTP 与 1 个自定义发信域。

用途
应用事务邮件、入站路由试验；日志仅保留 1 天。
日额度
100/日
月额度
无单独月顶（受日顶约束）
额度说明
Help Center「What does the Free plan offer」：100 messages per day；1 custom domain；1 day log retention；1 inbound route；2 API keys。定价页同口径。
是否绑卡
card=none — 官方写明 Free plan requires no credit card。
商用发信（免费档）
commercial=allowed — 面向应用发信的商业产品；Free 含 RESTful API 与 SMTP。仍须遵守反垃圾与域名认证要求。
证据句
help.mailgun.com Free plan: 100 messages/day, no credit card; mailgun.com/pricing Free $0/mo.

来源： What does the Free plan offer? Mailgun Pricing

报告本条过时/错误（预填 id=mailgun）

3. Postmark Free（Developer）

核验：2026-10-21 · 已核验

以送达率著称的事务邮件；免费 Developer 档仅 100 封/月，永不自动过期但额度紧。

用途
集成测试、评估送达、极低量侧项目。正式量级需 Basic 起（约 1 万封/月）。
日额度
无单独日顶（受月顶约束）
月额度
100/月
额度说明
定价页 Free：$0 · 100 emails/month · No overages allowed。FAQ：free developer plan never expires；未使用额度不滚动。
是否绑卡
card=none — 官网 CTA：Try Postmark Free · No Credit Card Required。
商用发信（免费档）
commercial=allowed — 允许事务/广播分 Message Streams；免费档可用于真实发信但额度极低。账户外发审批等政策以 Postmark 当前流程为准。
证据句
postmarkapp.com/pricing Free 100 emails/month; FAQ free developer plan does not expire; no credit card required.

来源： Postmark Pricing Monthly pricing support

报告本条过时/错误（预填 id=postmark）

4. Amazon SES

核验：2026-10-21 · 已核验

AWS 原生事务/营销发信；便宜但账号与沙箱门槛高。2026-07-21 起新客户不再享有旧的 SES 专属每月 3000 条免费档。

用途
已在 AWS 生态、要按量扩展的事务邮件；需完成域名验证与（常）离开沙箱。
日额度
受 SES 发送配额/沙箱限制（控制台）
月额度
见 AWS Free Tier / 定价计划
额度说明
定价页：Essentials/Pro/Enterprise 按千封计费，或 à la carte 约 $0.10/千封（出站）。AWS Free Tier：新客户最高约 $200 credits（注册可选 free plan 约 6 个月等，以 AWS Free Tier 文档为准）。Messaging Blog：2026-07-21 起新客户不再提供 SES 专属「每月 3000 message charges × 12 个月」；仍在该专属档期内的老客户可继续用完剩余期限。
是否绑卡
card=required — 使用 SES 需 AWS 账户；支付方式以 AWS 注册/计费要求为准。沙箱阶段通常只能发给验证过的地址。
商用发信（免费档）
commercial=allowed — 设计用于生产事务与营销发信；遵守 SES 发送政策与反垃圾要求。
证据句
aws.amazon.com/ses/pricing AWS Free Tier credits; blog 2026-07-21 SES-specific free tier no longer for new customers.

来源： Amazon SES Pricing SES pricing plans blog SES FAQs

报告本条过时/错误（预填 id=amazon-ses）

5. Brevo Free

核验：2026-10-21 · 已核验

原 Sendinblue；免费档日发 300，API 齐全，邮件带「Sent with Brevo」贴纸。

用途
事务 + 营销一体起步；日量中等的侧项目。
日额度
300/日
月额度
约 9,000/月（若天天满发；无单独月顶）
额度说明
Help Center：Free 含 300 email sends/day，每日重置，未用完不滚动。事务邮件达日顶后最多约 1,000 封进入重试队列，超出不投递。可存最多 100,000 contacts。
是否绑卡
card=none — Free 无时限、无需信用卡（产品页与定价说明）。
商用发信（免费档）
commercial=conditional — 允许真实发信；Free 强制带 Sent with Brevo 标识。移除品牌需升级。
证据句
help.brevo.com Free plan: 300 emails/day, no time limit; branding sticker required on Free.

来源： Free plan limits FAQ Brevo Email API

报告本条过时/错误（预填 id=brevo）

用途
短期评估 Twilio SendGrid；长期用量需付费计划。
日额度
试用期内约 100/日
月额度
非永久免费档
额度说明
Twilio changelog / Support：新账号 60-Day Free Trial；Email API 约 100 emails/day（Marketing 另有联系人限制）。试用结束后需升级才能继续发。
是否绑卡
card=conditional — 试用注册流程以 Twilio/SendGrid 当前页为准；升级付费通常需支付方式。
商用发信（免费档）
commercial=allowed — 付费/试用均可发事务邮件；遵守 Twilio 可接受使用政策。
证据句
Twilio changelog: Changes to SendGrid Free Plan; Support: 60-Day Free Trial ~100 Email API/day.

来源： SendGrid Free Plan changelog 60-Day Free Trial overview Email API Pricing

报告本条过时/错误（预填 id=sendgrid）

7. Zoho ZeptoMail / CPaaS Email

核验：2026-10-21 · 已核验

Zoho 事务邮件（现并入 CPaaS 积分制）；第一份 email credit 免费，之后按积分购买。

用途
只要事务邮件、接受积分预付的团队；非营销群发定位。
日额度
验证前常见日顶（以控制台为准）
月额度
首份免费积分非每月刷新
额度说明
zoho.com/zeptomail/pricing（CPaaS）：Email — 10,000 emails per credit；First credit is free；付费积分有效期约 6 个月。属试用金/首充赠送，不是每月自动刷新的免费档。
是否绑卡
card=none — 可先用免费首份积分起步；续购积分才涉及付款。
商用发信（免费档）
commercial=allowed — 定位事务邮件；营销/群发需改用其他产品。
证据句
zoho.com/zeptomail/pricing.html：10,000 emails per credit; First credit is free; credits valid 6 months.

来源： Zoho CPaaS / ZeptoMail Pricing Getting started

报告本条过时/错误（预填 id=zeptomail）

选型速记（非赞助）： 要长期免绑卡 + 月量尚可 → Resend Free（3k/月·100/日）或 Brevo（300/日，带品牌）； 只要测送达 → Postmark Free（100/月）或 Mailgun（100/日）； 已在 AWS → SES（按量 + Free Tier credits，新客户无旧 3000/月专属档）； 别把 SendGrid 60 天试用写成「永久免费」。国内厂商（如阿里云邮件推送）待官方公开免费档文档可抓取后再补。
