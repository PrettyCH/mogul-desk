逐条说明

1. Google Gemini Developer API（Free Tier）

核验：2026-10-21

AI Studio 发 Key 即可调多款 Gemini；Free Tier 输入输出在定价页对多款 Flash 标为免费。

用途
聊天、多模态、部分 TTS；适合个人原型与学习。
官方限额
定价页：如 gemini-3.8-flash、3.6-flash、2.5 Flash / Flash-Lite 等 Free Tier 为 Free of charge（部分旗舰/Pro/图片模型 Free 不可用）。RPM / TPM / RPD 按模型与档位变化，官方要求在 AI Studio 查看当前限额；RPD 约太平洋时间午夜重置。Free Tier 数据可能用于改进产品。
是否绑卡
无需结算账户即可用 Free Tier。升级 Paid 需链接账单并预付（文档写最低约 $5 等）。

来源： Pricing Billing Rate limits Google AI Studio

2. GroqCloud API（Free）

核验：2026-10-21

LPU 推理，OpenAI 兼容端点；免费档按模型列 RPM/RPD/TPM/TPD。

用途
低延迟聊天与代码补全；组织级限额，多 Key 共享。
官方限额
公开 Rate Limits 表示例（以控制台为准）：如 openai/gpt-oss-120b、openai/gpt-oss-20b、qwen/qwen3.8-27b 约 30 RPM / 1K RPD / 8K TPM / 200K TPD。完整表见官方文档；账号 Limits 页为最终值。
是否绑卡
可在 console.groq.com 免费注册并创建 API Key；更高档为 Developer 付费计划。

来源： Groq Rate Limits API Keys

3. OpenRouter 免费模型（ID 以 :free 结尾）

核验：2026-10-21

聚合多家模型；免费变体有平台级请求上限，与付费模型不同。

用途
一条 API 试多个上游免费端点；适合实验，不适合硬实时生产。
官方限额
Limits 文档：免费变体默认 20 requests/minute；累计购买积分 < 约 10 时 50 requests/day；累计至少约 $10 后升至 1000 requests/day（分钟上限仍为 20）。可用 GET /api/v1/key 看 free_model_daily_requests。账户余额为负时免费模型也可能 402。
是否绑卡
可用 :free 模型起步；买积分才会要支付方式。未买满阈值则保持较低日上限。

来源： API Credit & Rate Limits OpenRouter

4. Cloudflare Workers AI

核验：2026-10-21

边缘侧推理；Free 与 Paid 都含每日 Neurons 免费配额，超额才计费。

用途
Workers / Pages 里调 Llama、Qwen、Whisper 等；按 Neurons 计量。
官方限额
定价页：所有人每日 10,000 Neurons 免费；UTC 00:00 重置。超额需 Workers Paid，约 $0.011 / 1,000 Neurons。部分前沿模型要求 Paid 或 AI Gateway 预付积分，Free 可能 403。
是否绑卡
Workers Free 计划含上述免费 Neurons；升级 Paid 才需支付方式。

来源： Workers AI pricing Limits

5. Mistral AI · Free mode

核验：2026-10-21

Studio 可建 API Key；Free mode 含每月 included usage，超限需开 pay-as-you-go。

用途
Mistral 自有聊天/补全模型；评估与原型。
官方限额
Usage and limits：Free mode「lets you create API keys and use included monthly usage within the limits shown on the Limits page」。具体 Tokens/min、Requests/sec 因模型而异，官方不在该页写死全局数字——以 Admin Panel → API → Limits 为准。
是否绑卡
Free mode 可不先开通按量付费；扩展额度才用 prepaid credits / 付费。

来源： Usage and limits Activate Studio & API key Mistral pricing

6. NVIDIA API Catalog（build.nvidia.com）

核验：2026-10-21

NIM / 托管模型目录；Developer Program 可免费调原型端点，非生产授权。

用途
浏览器试用与 POC；自托管 NIM 另需开发者许可（生产要 NVIDIA AI Enterprise）。
官方限额
产品 FAQ：Developer Program 对托管 API 端点免费用于 prototyping；具体 RPM 因模型/流量变化，账户界面显示当前限额（社区常提约 40 RPM 量级，以控制台为准，本站不写死）。明确：非生产用途。
是否绑卡
加入 NVIDIA Developer Program 即可起步；生产部署需 AI Enterprise 许可（另计）。

来源： NIM General FAQ build.nvidia.com

7. Fireworks AI · 新账号起步积分

核验：2026-10-21

Serverless 推理；新账号有小额预付积分，用完即停，不是按月永久免费。

用途
开源权重模型的托管推理（OpenAI 兼容端点）。
官方限额
官方 FAQ / 计费说明口径：新账号约 $1 starter credit；耗尽后需添加支付方式与积分才能继续。这是一次性赠金，不是每月刷新的免费档。
是否绑卡
文档与第三方汇总常写：起步积分阶段可不加支付方式；续用要绑卡充值。请以 Fireworks 当前注册流程为准。

来源： What happens when I finish my $1 credit Serverless overview Fireworks pricing

8. SiliconFlow（硅基流动国际站口径）

核验：2026-10-21

聚合多家开源模型的推理平台；定价页 FAQ 写明约 $1 免费积分起步。

用途
按 token 调用 DeepSeek / Qwen / GLM 等（具体上架模型以模型广场为准）。
官方限额
国际站定价 FAQ：「可以从 $1 的免费积分开始」；无最低消费承诺。免费积分用完后按价目表付费。中国站（siliconflow.cn）可能另有实名与免费模型列表，以对应控制台为准——本条按已抓取的 siliconflow.com 定价页描述。
是否绑卡
起步积分阶段通常可先注册试用；持续使用需充值。是否强制实名/绑卡以注册地区控制台为准（标黄提醒）。

来源： SiliconFlow 定价 SiliconFlow
