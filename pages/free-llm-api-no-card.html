逐条说明

1. Google Gemini API Free

核验：2026-10-21 · 已核验

AI Studio 发 Key 即可调多款 Gemini；Free Tier 输入输出在定价页对多款 Flash 标为免费。

用途
聊天、多模态、部分 TTS；适合个人原型与学习。
官方限额
freeType=recurring — freeType=recurring（Free Tier 持续提供，限额按日等重置）。定价页：多款 Flash / Flash-Lite 等 Free Tier 为 Free of charge（部分旗舰/Pro/图片模型 Free 不可用）。RPM / TPM / RPD 按模型与档位变化，官方要求在 AI Studio 查看；RPD 约太平洋时间午夜重置。Free Tier 数据可能用于改进产品。
是否绑卡
card=none — 无需结算账户即可用 Free Tier。升级 Paid 需链接账单并预付（文档写最低约 $5 等）。
证据句
Billing：New accounts begin on the Free Tier without linking a billing account. Pricing：select Flash models Free of charge on Free Tier.

来源： Pricing Billing Rate limits Google AI Studio

2. Groq Free

核验：2026-10-21 · 已核验

LPU 推理，OpenAI 兼容端点；免费档按模型列 RPM/RPD/TPM/TPD。

用途
低延迟聊天与代码补全；组织级限额，多 Key 共享。
官方限额
freeType=recurring — 公开 Rate Limits 表示例（以控制台为准）：部分模型约 30 RPM / 1K RPD 量级。完整表见官方文档；账号 Limits 页为最终值。
是否绑卡
card=none — 可在 console.groq.com 免费注册并创建 API Key；更高档为 Developer 付费计划。
证据句
console.groq.com/docs/rate-limits：Free tier RPM/RPD/TPM/TPD by model.

来源： Groq Rate Limits API Keys

报告本条过时/错误（预填 id=groq）

3. OpenRouter :free

核验：2026-10-21 · 已核验

聚合多家模型；免费变体有平台级请求上限，与付费模型不同。

用途
一条 API 试多个上游免费端点；适合实验，不适合硬实时生产。
官方限额
freeType=recurring — Limits 文档：免费变体默认 20 requests/minute；累计购买积分 < 约 10 时 50 requests/day；累计至少约 $10 后升至 1000 requests/day（分钟上限仍为 20）。可用 GET /api/v1/key 看 free_model_daily_requests。账户余额为负时免费模型也可能 402。
是否绑卡
card=none — 可用 :free 模型起步；买积分才会要支付方式。未买满阈值则保持较低日上限。
证据句
openrouter.ai/docs/api-reference/limits：free models 20 RPM；daily 50 if credits purchased < ~10, else 1000.

来源： API Credit & Rate Limits OpenRouter

报告本条过时/错误（预填 id=openrouter）

4. Cloudflare Workers AI

核验：2026-10-21 · 已核验

边缘侧推理；Free 与 Paid 都含每日 Neurons 免费配额，超额才计费。

用途
Workers / Pages 里调 Llama、Qwen、Whisper 等；按 Neurons 计量。
官方限额
freeType=recurring — 定价页（核验 2026-10-20 文档）：所有人每日 10,000 Neurons 免费；UTC 00:00 重置。超额需 Workers Paid，约 $0.011 / 1,000 Neurons。部分前沿模型要求 Paid 或 AI Gateway 预付积分，Free 可能 403。
是否绑卡
card=none — Workers Free 计划含上述免费 Neurons；升级 Paid 才需支付方式。
证据句
developers.cloudflare.com/workers-ai/platform/pricing：10,000 Neurons per day free; reset 00:00 UTC.

来源： Workers AI pricing Limits

报告本条过时/错误（预填 id=workers-ai）

card=none — Free mode 可不先开通按量付费；扩展额度才用 prepaid credits / 付费。
证据句
docs.mistral.ai usage-limits：Free mode included monthly usage; Limits page is source of truth.
