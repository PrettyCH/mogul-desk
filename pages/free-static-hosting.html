免费静态托管：额度、商用与自定义域名

面向个人开发者与独立站长。数字来自各平台公开文档（核验日期：2026-10-21（Asia/Shanghai））。政策会改，下结论前请点「来源」再看一眼。

怎么读这张表：「商用」指条款是否允许把免费档拿来跑生意站 / 卖货 / SaaS；不是「能不能挂广告」的绝对判决。Vercel Hobby 与 GitHub Pages 都有明确的非商用/非在线生意限制——这是很多人翻车的地方。

逐条说明

1. GitHub Pages

核验：2026-10-21

从仓库直接托管静态站；文档与开源项目最省事，但明确禁止当免费商业主机。

用途
个人站、项目文档、组织展示页；默认 *.github.io。
免费额度
发布站点 ≤ 1 GB；带宽软上限约 100 GB/月；软限制约每小时 10 次构建（自定义 Actions 工作流不受此限）。
商用
官方写明：不打算也不允许用作免费 Web 主机去跑在线生意、电商，或主要促成商业交易 / 提供商业 SaaS 的网站。
备注
免费账号上公开仓库即可用；敏感交易（密码、信用卡）也不适合放这里。

来源： Pages limits About Pages

2. Cloudflare Pages

核验：2026-10-21

边缘 CDN 上的静态站；Free 档构建次数与文件数是硬门槛，静态流量通常很宽裕。

用途
博客、文档、营销落地页；可接 Pages Functions（计入 Workers 配额）。
免费额度
每月 500 次构建、同时 1 个构建；每站最多 20,000 文件、单文件 25 MiB；每账号最多 100 个项目；Free 每项目最多 100 个自定义域名。
商用
平台介绍与定价页强调静态请求免费；公开对照文常写「未见等同 GitHub/Vercel 的非商用禁令」。正式商用仍应读当前 ToS。
备注
Cloudflare 现更推荐用 Workers + Static Assets 开新项目；Pages 仍可用。

来源： Pages limits Workers & Pages pricing

3. Vercel Hobby

核验：2026-10-21

Next.js / 前端实验友好；Hobby 明文限非商用个人用途。

用途
个人项目、演示、学习；框架集成强。
免费额度
含 Fast Data Transfer 100 GB、Fast Origin Transfer 10 GB、CDN Requests 100 万、Function Invocations 100 万、Active CPU 4 小时等（按月）；最多 200 项目、每项目 50 域名、每天 100 次部署。
商用
Fair Use：Hobby 仅限 non-commercial, personal use；卖产品/服务、广告变现等需 Pro。
备注
多数额度用超后需等约 30 天周期恢复（部分分析类暂停更短）。

来源： Hobby plan Fair Use Guidelines

4. Netlify Free（Credit-based）

核验：2026-10-21

2025-09-04 后新账号用积分制：Free 每月 300 credits，耗尽硬停。

用途
静态站 + 表单、预览部署；适合中小流量实验。
免费额度
300 credits/月（不可自动充值）。带宽约 20 credits/GB；生产部署每次 15 credits；Web Requests 约 2 credits / 1 万次。若几乎只烧带宽，大约折合十几 GB 量级。
商用
Credit-based 文档强调 Free 适合小实验；未在同页写死「禁止商用」。额度耗尽后项目会暂停直到下个周期。
备注
旧账号可能仍是 Legacy 套餐；本文按新积分制描述。

来源： Credit-based plans Pricing

5. Render Static Sites

核验：2026-10-21

静态站本身免费部署，但流量与构建分钟计入工作区月度配额。

用途
前端站、文档、博客；全局 CDN、自动 HTTPS、PR 预览。
免费额度
静态站免费部署。Hobby 工作区每月含 5 GB 出站带宽；超出且未绑支付方式时，服务可能被挂起至下月。
商用
文档未把静态站限定为「仅个人」；适合有预算绑卡的小生意站，但 5 GB 对图片站很紧。
备注
Hobby 含 2 个自定义域名额度，超出按文档另行计费。

来源： Static Sites Outbound bandwidth Deploy for Free

6. Surge.sh

核验：2026-10-21

命令行把本地文件夹发布成静态站；免费档强调无限发布 + 自定义域名 + 基础 SSL。

用途
快速预览、简单落地页、课程作业站。
免费额度
定价页：Unlimited publishing、Custom domain、Basic SSL。Professional（约 $30/月）才有强制 HTTPS、自定义重定向、密码保护等。
商用
定价页未写「禁止商用」；生产向功能多在 Professional。请自行阅读当前条款。
备注
部署 API 文档另有单项目文件数/体积一类限制，大规模站请先查 API docs。

来源： Pricing Getting started

7. GitLab Pages

核验：2026-10-21

跟 GitLab CI 产物绑定；适合已经在 GitLab 上的文档与项目站。

用途
项目文档、静态站点；默认 *.gitlab.io。
免费额度
GitLab.com：站点最大 1 GB；每站最多 150 个自定义域名；支持 TLS。带宽无固定公开硬顶（滥用仍可能受限）。
商用
gitlab.com 设置页列出技术上限，未在同页写「禁止商用」；正式用途请读 GitLab 服务条款。
备注
站点大小与 CI artifact 上限相关（GitLab.com artifact 压缩上限 1 GB）。

来源： GitLab.com settings（含 Pages） GitLab Pages

8. Firebase Hosting（Spark / 免费用量）

核验：2026-10-21

Google 全球 CDN 静态托管；免费档有明确存储与月传输上限。

用途
Web App 前端、活动页；与 Firebase 生态集成方便。
免费额度
Hosting 存储前 10 GB 免费；CDN 数据传输前约 10 GB/月 免费。单文件最大 2 GB。
商用
可用于生产，但 Spark 超量后站点可能在宽限期后被禁用，直到下月或升级 Blaze。
备注
配额按项目计，不是按站点。建议在 Cloud Console 设预算告警。

来源： Usage quotas & pricing Firebase Pricing

选型速记（非赞助）： 纯文档/开源展示 → GitHub Pages； 可能商用、要流量余量 → 优先看 Cloudflare Pages； Next.js 个人实验 → Vercel Hobby（别拿去卖货）； 已在 GitLab → GitLab Pages； 要和 Firebase 后端一起 → Firebase Hosting。
