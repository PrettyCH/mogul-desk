免费 TTS / 语音合成 API：额度与是否绑卡

面向想给博客、客服机器人、播客草稿加语音的开发者。数字来自各平台公开文档（核验：2026-10-21，Asia/Shanghai）。枚举：card=none|required|conditional|unverified。政策会改，下结论前请点「来源」。

怎么读：「免费额度」只写官方写明的字符/次数；筛「免绑卡起步」= card=none。云厂商（Azure / GCP / AWS）多数要先开订阅并留支付方式，即使本月可能 $0。Edge TTS 不是官方产品，商用风险单独标出。

逐条说明

1. Azure Speech F0

核验：2026-10-21 · 已核验

微软云语音；免费档神经 TTS 按字符计月额度，适合小流量试听与原型。

用途
应用内朗读、客服提示音、多语言神经音色合成。
免费额度
定价页 Free (F0)：Neural Text to Speech 0.5 million characters free per month（50 万字符/月）。配额文档：F0 实时 TTS 约 20 transactions / 60 seconds；F0 无 Batch synthesis。
是否绑卡
card=required — 需 Azure 订阅。标准免费/即用即付账户常见要信用卡验证；Azure for Students 等学生计划可能不需卡（以微软当前注册页为准）。F0 本身按定价页为免费额度。
证据句
Free (F0) table: Neural Text to Speech — 0.5 million characters free per month.

来源： Azure Speech pricing Quotas and limits

2. Google Cloud TTS

核验：2026-10-21 · 已核验

GCP 上的经典 TTS；按月有免费字符档，超量自动计费——所以必须开结算。

用途
多语言 Standard / WaveNet / Neural2 / Chirp 3 HD / Studio 等音色；适合有 GCP 项目的后端合成。
免费额度
定价页（按月、按字符）：Standard 与 WaveNet 免费至 4 million 字符；Neural2、Chirp 3: HD、Studio 等免费至 1 million 字符。Instant custom voice 与部分 Gemini-TTS（Cloud 侧）可能无此免费档。
是否绑卡
card=required — 官方写明：You must enable billing to use Text-to-Speech；超量会自动扣费。等于要开 GCP 结算账户（通常要支付方式）。
证据句
Pricing：Standard/WaveNet free up to 4M chars/month；Neural2/Chirp 3 HD/Studio free up to 1M；billing required.

来源： Text-to-Speech pricing Quotas & limits

报告本条过时/错误（预填 id=google-cloud-tts）

3. ElevenLabs Free

核验：2026-10-21 · 已核验

创作者向语音 API；Free / Pay-as-you-go 档有少量含字符量，API 与网页共用。

用途
高质量多语 TTS、有声内容草稿；也有 STT / 音效等。
免费额度
API 定价对照表 Free/Pay-as-you-go：v4 TTS Characters included 10,000（约 10 min）。更高档订阅另计。商用许可：对比表中 Free 的 Commercial use 常为空，Starter 起才列——商用请读当前条款。
是否绑卡
card=none — 可注册使用 Free；付费订阅才需信用卡 / Apple Pay / Google Pay（定价 FAQ）。
证据句
elevenlabs.io/pricing/api model table: Free / Pay as you go — v4 Characters included 10,000.

来源： ElevenLabs API Pricing ElevenLabs Pricing

报告本条过时/错误（预填 id=elevenlabs）

4. OpenAI Speech（tts-1 等）

核验：2026-10-21 · 已核验

OpenAI 音频 Speech 端点；按字符或 token 计费，Free 档有严格地区与速率限制。

用途
/v1/audio/speech 文本转语音；tts-1 偏速度，tts-1-hd 偏质量，gpt-4o-mini-tts 按 token 计费。
免费额度
Usage tiers：Free 档「User must be in an allowed geography」。模型页示例：tts-1 Free 约 3 RPM / 200 RPD。定价页：tts-1 / tts-1-hd 按字符计费。不在允许地区则无 Free 档。
是否绑卡
card=conditional — Free 档在允许地区可起步；Build 及以上要累计购积分。实际是否强制留卡以账号控制台为准。
证据句
OpenAI rate limits / usage tiers：Free geography-gated；tts-1 Free RPM/RPD 以模型页为准。

来源： OpenAI Pricing tts-1 model Rate limits

报告本条过时/错误（预填 id=openai-tts）

5. Amazon Polly

核验：2026-10-21 · 已核验

AWS 文本转语音；Standard 有较大的按月免费字符量，Neural 等多为新账号首年额度。

用途
应用朗读、无障碍、Speech Marks 口型同步等。
免费额度
定价页 Free tier：Standard 5 million characters/month；Neural 1 million/month（首 12 个月）；Long-Form 50 万/月（首 12 个月）；Generative 10 万/月（首 12 个月）。2025-07-15 起新客户另有 AWS Free Tier credits 说明。
是否绑卡
card=required — 一般需 AWS 账户与支付方式；免费额度用完或超出 Free Tier 后按字符计费。
证据句
aws.amazon.com/polly/pricing Free tier: Standard 5M chars/month; Neural 1M/month first 12 months.

来源： Amazon Polly Pricing

报告本条过时/错误（预填 id=amazon-polly）

6. Edge TTS（开源封装）

核验：2026-10-21 · 已核验

社区项目通过 Microsoft Edge 在线 TTS 通道合成；无 Key、无账单，但也无官方 SLA。

用途
本地脚本、个人工具快速出音频；PyPI 包 edge-tts（如 rany2/edge-tts）常见。
免费额度
无微软官方「每月 X 字符」公开表。可用性取决于 Edge 在线服务与客户端行为，可能随时变更或限流。
是否绑卡
card=none — 不需要 API Key 或绑卡。商用/再分发音频：微软社区答复常建议改用 Azure AI Speech；本站不声称其可商用。
证据句
非官方产品；见 GitHub rany2/edge-tts 与 Microsoft Q&A 商用讨论。

来源： rany2/edge-tts edge-tts on PyPI Microsoft Q&A（商用讨论）

7. 讯飞开放平台在线合成

核验：2026-10-21 · 已核验

国内常用中文 TTS；创建应用后有按日免费调用次数，适合中文原型。

用途
App / 网页中文朗读；基础发音人文档写明免费赠送，特色发音人另购。
免费额度
服务说明：登录并创建应用后，每天可免费调用语音合成 SDK 与 Web API 共计 500 次；另可在官网领取免费次数包（每账号一次，以领取页为准）。
是否绑卡
card=none — 国内开放平台流程以实名认证与控制台开通为主；起步免费次数不要求国际信用卡。正式商用额度与审核规则以讯飞当前协议为准。
证据句
xfyun.cn 在线语音合成服务说明：每日 SDK+WebAPI 合计 500 次。

来源： 在线语音合成服务说明 在线语音合成 API

8. Gemini API TTS

核验：2026-10-21 · 已核验

走 Google AI Studio / Gemini API，而不是 Cloud Text-to-Speech；多款 Flash TTS 在 Free Tier 标价为免费。

用途
用 Gemini 系 TTS 模型做可控语音合成。
免费额度
定价页多款 Flash TTS 在 Free Tier 列为 Free of charge。具体 RPM / TPM / RPD 因模型与账户档位而异，官方要求在 AI Studio 查看当前限额；Free Tier 内容可能用于改进产品。
是否绑卡
card=none — Billing 文档：New accounts begin on the Free Tier，无需先链接结算账户。升级 Paid 才需绑卡并预付（最低约 $5 等）。
证据句
ai.google.dev Gemini API pricing + billing：Free Tier without linking billing first.

来源： Gemini API pricing Billing Rate limits
